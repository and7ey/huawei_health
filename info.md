# Huawei Health для Home Assistant

Читает данные из **собственного облака приложения Huawei Health** (`com.huawei.health`) —
того же, в которое часы синхронизируют статистику. Телефон, браслет и само приложение во
время работы Home Assistant не нужны.

- **Нужен только браузер** — один раз за 180 дней: интеграция выдаёт ссылку входа, а код
  разрешения вставляется обратно в диалог настройки. Обход капчи не используется.
- **Мобильный режим браузера обязателен**: кнопка «Разрешить» на странице согласия Huawei
  реагирует только на касание, не на клик (в Chrome: F12 → Ctrl+Shift+M → выбрать
  устройство → Reload).
- **Код берётся из консоли браузера** — из строки вида
  `Failed to launch 'hms://redirect_url?code=…' because the scheme does not have a registered handler.`

## Сенсоры

Шаги, дистанция, калории, активность, ходьба, активные часы, интенсивные минуты, цель по
шагам; пульс (покоя/текущий/макс/мин); сон (длительность, глубокий, REM, поверхностный,
бодрствование, оценка, эффективность, ВСР, SpO2); стресс; последняя тренировка (тип,
длительность, дистанция, калории) и их число в окне; счётчик дней до следующего входа.

## Особенности

- **Несколько аккаунтов** — каждая запись интеграции со своими токенами и настройками.
- Токены ротируются автоматически и сразу сохраняются в конфигурационную запись.
- Суточные суммы совпадают с приложением; тренировки собираются из поминутных сегментов с
  дедупликацией (иначе часы и телефон считаются дважды).
- Только стандартная библиотека Python, зависимостей из PyPI нет.

Полная инструкция, разбор схемы работы и коды ошибок — в
[README](https://github.com/and7ey/huawei_health/blob/main/README.md).
